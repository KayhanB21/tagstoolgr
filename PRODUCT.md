# Product

## Register
product

## Users
Thunderbird users tagging or clearing tags on one or many selected messages.

## Product Purpose
Apply multiple existing Thunderbird tags in one action, or clear all tags. Expose the workflow through the unified toolbar and message context menu.

## Design direction
The user delegated remaining choices. Use a quiet, familiar utility interface matching Thunderbird, with native controls, visible keyboard focus, descriptive text, and tag colors paired with names. Avoid decorative dashboards or color-only meaning. Add is the default; replace is explicit. The supplied Parthenon image will become the final icon.
